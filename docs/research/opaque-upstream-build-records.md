## Artifact metadata limits

The package's public build script bundles the `.wasm` into JavaScript via Rollup and packages only declarations and ESM/CJS entry points. The registry artifact digest authenticates those bytes, but neither that digest nor the verified provenance predicate enumerates Cargo packages. The embedded module is a compiled WASM payload, not a lockfile/SBOM. No reliable mapping from embedded compiler metadata to the full crate graph, enabled transitive features, license expressions, or advisory call reachability was recovered. `wasm-bindgen`/Rust tool versions may sometimes be inferred from build metadata or symbols, but such inference would not reconstruct the lock resolution and is not evidence for this artifact's exact graph. Therefore no partial tool/version guess is promoted to a finding.
